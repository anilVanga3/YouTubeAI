# YouTubeAI - Automatic Video Generator and Uploader

YouTubeAI is a fully automated system that generates short videos daily on random topics, including voiceovers, background music, and visuals. It schedules and uploads the videos to YouTube using the YouTube Data API.

## Features
- **Random Topic Selection**: Topics are selected randomly from a predefined list.
- **Video Creation**:
  - Text-to-speech voiceovers.
  - Animated text visuals.
  - Background music or stock visuals.
- **Automatic Upload**:
  - Videos are uploaded to YouTube with titles and descriptions.
- **Daily Scheduling**: The system generates and uploads videos automatically at a set time.

## Topics Covered
1. Business ideas in India.
2. Global education insights.
3. Anime updates, recaps, and wow moments.
4. Daily world news.
5. Motivational quotes.
6. Sports (cricket-focused).
7. Health tips, exercises, and yoga.
8. Untold history of the world.
9. Facts about the universe.

## File Structure
- **main.py**: Orchestrates the daily workflow of topic selection, video creation, and uploading.
- **topics.py**: Handles topic selection logic.
- **video_maker.py**: Creates videos using `moviepy` and `pyttsx3`.
- **uploader.py**: Uploads videos to YouTube via OAuth.
- **client_secret.json**: Contains OAuth credentials for YouTube API.

## Setup Instructions
### Prerequisites
1. **Python**: Ensure Python 3.7+ is installed.
2. **Install Dependencies**:
   ```bash
   pip install moviepy pyttsx3 schedule google-auth google-auth-oauthlib google-auth-httplib2 google-api-python-client
   ```

### Configure YouTube API
1. Go to [Google Cloud Console](https://console.cloud.google.com/).
2. Create a project and enable the **YouTube Data API v3**.
3. Download the `client_secret.json` file and place it in the root directory of this project.

### Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/anilVanga3/YouTubeAI.git
   cd YouTubeAI
   ```
2. Run the script:
   ```bash
   python main.py
   ```

## How It Works
1. **Daily Task**: At a scheduled time, the script selects two random topics.
2. **Video Generation**:
   - For each topic, two short videos are created (30 seconds each).
   - Text and voiceovers are generated dynamically.
3. **YouTube Upload**:
   - Videos are uploaded with autogenerated titles and descriptions.
4. **Fully Automated**: After setup, the system runs without manual intervention.

## Notes
- Make sure the `client_secret.json` is correctly configured for OAuth.
- Generated videos are stored in the `videos/` directory.
